{%- comment -%} A scroll-snapping strip of pictures, with a caption and a dot per slide. It is a scroll container, not a slideshow: the browser does the paging, so it works with a finger, a trackpad, a scrollbar and the arrow keys before a single line of JavaScript runs. The buttons and the dots are progressive enhancement (assets/scripts/carousel.js). Params: items (list of {src, alt, caption}), fallback (one image path), label (accessible name). {%- endcomment -%} {%- assign shots = include.items -%} {%- if shots.size > 0 -%} {%- elsif include.fallback and include.fallback != site.placeholder_image -%} {%- endif -%}
