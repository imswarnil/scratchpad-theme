  1. 1

    Get it on your machine

    One command. It clones the theme, drops its history so the first commit is yours, clears the demo content and opens the setup form.

    npx scratchpad-theme my-site

    Ruby 3.4 and Node 18+. The macOS system Ruby cannot build this — use bin/serve rather than calling Jekyll directly.

  2. 2

    Answer the form

    Your name, the accent colour, which collections you want, the header, the footer, your links. It serves one page on 127.0.0.1, uploads nothing, and backs up everything it replaces before it writes.

    npm run setup

    Safe to run again whenever you like — it opens pre-filled from your current config.

  3. 3

    See it

    npm run dev      # http://localhost:4000

    npm run doctor will tell you about anything half-configured before it bites — a missing cover, an endpoint you have not set.

  4. 4

    Write something

    A post is a Markdown file in _posts/, named YYYY-MM-DD-slug.md. npm run new scaffolds one in any collection with the right front matter.

    Writing a post

  5. 5

    Put it online

    Create a repository named username.github.io, push to main, then Settings → Pages → Source: GitHub Actions.

    The workflow passes GitHub's own base path to Jekyll, so the same setup is correct for a user page and a project page. You never set baseurl by hand.
