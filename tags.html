--- layout: default title: Tags permalink: /tags/ description: "Every tag on the site, and everything filed under it — across all five collections." ad_rails: false --- {%- comment -%} Cross-collection tag index. Every tag used by any entry in any collection gets a chip in the cloud and a section of its own below it, so a tag link on a post has somewhere real to land: /tags/#t-. Liquid has no cross-collection tag map — `site.tags` only ever sees posts — so the index is built here, which keeps the page buildable on GitHub Pages with no plugin. Tags are grouped by their SLUG, not by their spelling, so `Analytics` and `analytics` are one subject with one anchor rather than two sections sharing a duplicate id. The first spelling seen (newest entry first) is the one displayed. The index is carried in one string of `slug::label::count` records because Liquid cannot build an array of objects. A tag containing `|` or `::` would split wrongly — no real tag does, and a slug never can. {%- endcomment -%} {%- assign entries = "" | split: "" -%} {%- for c in site.collections -%} {%- assign entries = entries | concat: c.docs -%} {%- endfor -%} {%- assign entries = entries | sort: "date" | reverse -%} {%- comment -%} 1. unique slugs, each with the first spelling seen {%- endcomment -%} {%- assign seen = "|" -%} {%- assign pairblob = "" -%} {%- for d in entries -%} {%- for t in d.tags -%} {%- assign sl = t | slugify -%} {%- assign key = "|" | append: sl | append: "|" -%} {%- unless seen contains key -%} {%- assign seen = seen | append: sl | append: "|" -%} {%- assign pairblob = pairblob | append: sl | append: "::" | append: t | append: "|" -%} {%- endunless -%} {%- endfor -%} {%- endfor -%} {%- assign pairs = pairblob | split: "|" | sort_natural -%} {%- comment -%} 2. count each one once, so the cloud and the headings agree {%- endcomment -%} {%- assign statblob = "" -%} {%- for pair in pairs -%} {%- assign bits = pair | split: "::" -%} {%- assign sl = bits[0] -%} {%- assign n = 0 -%} {%- for d in entries -%} {%- assign hit = false -%} {%- for t in d.tags -%} {%- assign ts = t | slugify -%} {%- if ts == sl %}{% assign hit = true %}{% endif -%} {%- endfor -%} {%- if hit %}{% assign n = n | plus: 1 %}{% endif -%} {%- endfor -%} {%- assign statblob = statblob | append: pair | append: "::" | append: n | append: "|" -%} {%- endfor -%} {%- assign stats = statblob | split: "|" -%}
